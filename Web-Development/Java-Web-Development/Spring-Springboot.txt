Spring / Springboot:
	Abbreviations: 
	
	Description: 
		Spring: A Framework that provides Comprehensive Infrastructure Support (Libraries / Modules) for Java Applications.
		SpringBoot: A Bootstrap / Extension of the Spring Framework which elimnates much of the Boilerplate Configuration required for setting up Spring Applications.
	
	Resources:
		Spring Initializer: https://start.spring.io/ // A Website for Generating Spring Configuration Files
	
	Concepts:
		JAR Files: Java Archive. Contains Libraries, Resources and Assets.
		WAR Files: Web Application Archive. Contains the Web Application in a specific structure that can be deployed on any Web Container / Java Application Server.
		EAR Files: Enterprise Application Archive. Contains both JAR and WAR Files. It contains additional Application Metadata as well.

		Spring Component: A Class that is marked by a Spring Stereotype Annotation. When the Container instantiates it, the instance is considered a Spring Bean.

		JavaBean: A Class whose Constructor is public with no arguments, Properties are all private, but are accessible via Getters and Setters.
		Spring Bean: A Container-managed Object. It is an Instance of a Class, instantiated by a Spring Component. This is not necessarily a JavaBean; they are two unrelated concepts.
	
	Details:
		Spring / Springboot may seem bloated and heavyweight, but that is because it provides a superb set of Industrial Strength Solutions suited for Heavy Enterprise Applications.

		Java:
			// Configuration: Register Beans here to allow Spring to automatically send these into Spring Components:
				// Tip: A Bean that defines other Beans.
				@Configuration
				public class <application-dependency-configuration> {
					@Bean @Profile("<env>")
						// @Bean - Tells Spring to treat and manage the returned Dependency as a SpringBean.
						// @Profile - Tells Spring to only use this when the SPRING_PROFILES_ACTIVE contains the "<env>"
					public <dependency-type> <config-method>(
						@Value("${<application-property-field>:<default-value>}")
						String configValue,
					) { 
						return new <dependency-type>(configValue);
					}
				}

				// OR

				@ConfigurationProperties(prefix = "<application-property-field-prefix>")
				public record <application-property-field-object>(
					<type> configValue,
					// ...
				) {}

				@Configuration
				@EnableConfigurationProperties(<application-property-field-object> configObj)
				public class <application-dependency-configuration> {
					@Bean
					public <dependency-type> <config-method> (<application-property-field-object> configObj) {
						return new <dependency-type>(configObj.configValue, ... );
					}
				}
